A git repository rehosting the [`very_nauty`](http://keithbriggs.info/very_nauty.html) graph library by Keith Briggs. The purpose of this repository is to simplify inclusion of `very_nauty` in other software tools and frameworks.

The initial commit `0f521d9adce5f4fe8549ebfc7a9bb64f6d299299` is exactly the content of the v1.1 archive of the library. Additional commits have been added to clarify licensing and other administrivia, with Keith's guidance and consent. Keith is the sole copyright holder of `very_nauty`.
